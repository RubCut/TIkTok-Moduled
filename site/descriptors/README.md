# Descriptor'ы модулей

Файлы `*.json` в этом каталоге — авторские descriptor'ы (ТЗ §10.2). Они
публикуются вместе с релизом: скрипт `.github/scripts/publish-descriptors.py`
берёт готовые ZIP модулей из артефактов сборки, считает SHA-256 точных байтов
архива и генерирует descriptor'ы.

Пока релиз не опубликован, descriptor'ы отсутствуют, и установка из каталога
честно завершается ошибкой `DESCRIPTOR_FETCH_FAILED` (404) — каталог не
притворяется рабочим.
