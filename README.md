# TikTok Moduled (TModules)

Платформа модулей для TikTok по техническому заданию `ТЗ_TikTok_Moduled.md`:
патчер APK, runtime/загрузчик DEX, менеджер TModules, редактор непрозрачных
конфигов, каталог/репозитории, диагностика, safe mode, MD3 UI, комплектный
модуль региона, необязательный менеджер внутри приложения и сайт-каталог.

## Статус

Первая рабочая поставка. Ключевые ограничения честно зафиксированы:

- **B-001 (исходный обработчик сбоев)** — дефект НЕ закрыт: реального stack
  trace с устройства не было. Поставлен диагностический контур
  (`core/CrashReports`, проверка записи и замены handler, журнал в экране
  диагностики). Закрытие возможно только по фактическому отчёту с устройства
  (ТЗ §18.6, §25).
- **Native hook backend** — контракт (`HookBackend`, `HookApi`) и диагностика
  доступны; конкретная native-реализация (перехват ART) в поставку не входит
  (§27: открытое решение). Патч без `.so` возможен: модули без хуков работают,
  недоступность перехвата видна в плане патча и диагностике.
- **Production-подпись** — отделена (ADR-0002): автоматически создаётся только
  разработческий самоподписанный ключ во внутреннем хранилище.

## Модули репозитория

| Модуль | Назначение |
| --- | --- |
| `core` | общие правила: лимиты, хеши, манифесты, валидаторы, снимок, мост-контракт, descriptor, каталог, политика URL |
| `module-api` | контракт автора модуля (`apiVersion: 1`, фиксирован) |
| `runtime` | bootstrap, загрузка DEX, хуки, снимки, safe mode, crash-контур; встраивается в хост, НЕ зависит от MD3 |
| `patcher` | анализ APK, профиль совместимости, план, правка AXML manifest, пересборка, подпись apksig, проверка |
| `standalone-ui` | общие MD3-компоненты самостоятельных приложений |
| `manager` | TModules: 9 экранов, хранилище модулей, снимки, мост (ContentProvider), каталог, настройка |
| `demo-host` | тестовый хост с отметкой для приёмки на эмуляторе (§26.2) |
| `sample-module` | эталонный модуль-пример |
| `region-module` | комплектный модуль региона (§16) |
| `inapp-manager` | необязательный менеджер внутри хоста (§17) |
| `site` | статический каталог GitHub Pages (§13) |
| `docs` | архитектура, ADR, методика НФТ, модерация каталога |

## Сборка

Требуется JDK 17 и Android SDK (platforms;android-35, build-tools;35.0.0).
Репозитории объявлены в `settings.gradle`. Сборка и тесты — через GitHub
Actions (`.github/workflows/ci.yml`): `./gradlew ciTest ciAssembleDebug ciLint`.

Локально:

```bash
./gradlew ciTest            # все JVM/Robolectric-тесты
./gradlew ciAssembleDebug   # APK менеджера и демо-хоста
./gradlew :sample-module:packageModule :region-module:packageModule :inapp-manager:packageModule
```
