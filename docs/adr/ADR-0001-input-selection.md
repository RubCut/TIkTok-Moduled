# ADR-0001: выбор входного APK, Android-версии и ABI (§28)

**Статус:** принято (первая поставка).

**Решение.** Входной APK выбирает пользователь через системный выбор файла
(SAF). Профиль совместимости создаётся по фактическому анализу входа:
package ID, versionCode, min/targetSdk и присутствующие ABI. Пользователь
явно выбирает ABI для native hook backend (по умолчанию arm64-v8a); лишние
ABI исключаются из результата (PAT-05).

**Обоснование.** Исходников TikTok нет, конкретная версия не зафиксирована в
ТЗ; анализ входа + явный профиль дают воспроизводимость и честный отказ при
несовместимости вместо догадок.

**Последствия.** Для каждой новой версии TikTok профиль создаётся заново
(автоматически по анализу); точка входа выбирается по фактическому manifest
(PAT-08), а не по жёсткой таблице версий.
