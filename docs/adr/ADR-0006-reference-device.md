# ADR-0006: эталонное устройство (§28)

**Статус:** открытое решение — устройство не предоставлено.

**Решение (временное).** Приёмка на эмуляторе: demo-host (тестовый хост с
отметкой) + патченный демо-APK, Android 14 (API 34/35), arm64-v8a. Реальное
устройство с TikTok требуется для:

- фактической проверки точки входа и поведения оригинального Application;
- замеров НФТ (§23: p95 ≤ 200 мс, +20 MiB PSS, ≥ 30 запусков — методика в
  `docs/NFR_METHOD.md`);
- получения реального stack trace B-001 (§18.6) — единственного основания
  закрыть дефект.

**Последствия.** До предоставления устройства указанные пункты остаются
неподтверждёнными; это отражено в отчёте поставки (§26.5) без имитации.
