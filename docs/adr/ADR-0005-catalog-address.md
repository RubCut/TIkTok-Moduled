# ADR-0005: адрес каталога и модерация (§13, §28)

**Статус:** принято.

**Решение.** Каталог первой поставки — GitHub Pages репозитория:
`https://rubcut.github.io/TIkTok-Moduled/catalog.json`. Descriptor'ы —
`site/descriptors/<id>.json`, архивы — файлы релизов GitHub. Модель модерации
описана в `docs/CATALOG_MODERATION.md`: в основной каталог попадают модули,
собранные CI этого репозитория; сторонние — только решением сопровождения.

Пользователь может добавить любой свой источник (HTTPS). Ошибка источника не
уничтожает кеш; дубли ID между источниками показываются для выбора.

**Последствия.** Смена адреса каталога — конфигурационное изменение
(источники хранятся в `sources.json`), не требующее обновления кода.
