# ADR-0007: лицензия (§28)

**Статус:** открытое решение.

**Текущее состояние.** В репозитории присутствует `LICENSE` — GNU AGPL v3.0
(файл существовал до начала работ и не заменялся, чтобы не менять правовое
положение чужого репозитория без решения владельца).

**Решение.** Окончательный выбор лицензии — за заказчиком (§28). Возможные
варианты и последствия:

- **оставить AGPL-3.0** — любая модификация, распространяемая как сервис,
  обязана публиковать исходники; для патчера сторонних APK это может быть
  неприемлемо;
- **Apache-2.0** — совместим с зависимостями (apksig, Material, BouncyCastle),
  патентная оговорка;
- **проприетарная** — требуется заменить LICENSE и указать правообладателя.

Сторонние зависимости остаются под своими лицензиями: AGP/apksig и Material
Components — Apache 2.0, BouncyCastle — лицензия MIT-типа. Конфликтов с
любым из вариантов нет.

**Действие для закрытия:** решение заказчика → замена/подтверждение `LICENSE`
и запись в отчёт поставки (§26.5).
